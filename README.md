# Зерно — мини-магазин кофе

Учебный интернет-магазин на PHP (PDO + SQLite), HTML, CSS и JavaScript.

## Возможности
- Каталог товаров и страница товара
- Корзина (хранится в сессии), изменение количества без перезагрузки страницы
- Оформление заказа с проверкой данных на сервере
- Админка: добавление, редактирование и удаление товаров, список заказов

## Запуск
Нужен PHP 8.0+ с расширениями `pdo_sqlite` и `mbstring`.

```
php -S localhost:8000
```

Откройте http://localhost:8000. База данных `data/shop.db` создаётся и заполняется при первом запуске.
Админка: http://localhost:8000/admin.php, пароль по умолчанию задан в `inc.php` (константа `ADMIN_PASSWORD`).

## Дизайн
Адаптивная вёрстка без фреймворков, упаковки кофе нарисованы inline-SVG (цвет берётся из базы), поэтому картинки не нужны.

## Структура
- `inc.php` — подключение к БД, таблицы, общие функции, шапка и подвал
- `index.php`, `product.php`, `cart.php`, `checkout.php`, `admin.php` — страницы
- `cart.js` — обновление корзины через fetch
- `style.css` — стили

## Безопасность
Запросы к БД выполняются через подготовленные выражения (PDO), весь вывод экранируется через `htmlspecialchars`, формы защищены CSRF-токеном.
